# Abdullah All Mansur — Personal Portfolio

A responsive, single-page personal portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — responsive layout, colors and theme styles
- `script.js` — theme toggle, mobile navigation and small interactions
- `assets/ict-club-certificate.jpg` — certificate image supplied for this portfolio

## Preview locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a new public repository. A convenient repository name is `your-username.github.io` (replace with your GitHub username).
3. Upload all files and the `assets` folder, keeping the same folder structure.
4. If using a regular repository instead, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the Pages deployment to finish. GitHub will show your website URL in Settings → Pages.

## Before publishing
- Replace `your-email@example.com` in `index.html` with an email address you want to make public.
- Replace the GitHub and LinkedIn links with your actual public profile URLs.
- Review the project descriptions and update them so they accurately describe your work.
- Add your own project screenshots and photography when ready.
- Keep private details such as your home address, phone number and personal documents off the public site.

## Customize
Edit the text in `index.html`. Adjust colors and spacing in `style.css`. The theme preference is stored in the visitor's browser using local storage.
